# 多组件架构

采用单仓库、多独立包的结构。keyboard 是第一个组件，日历和图表先保留扩展方向，不创建没有实现的额外包。

## 依赖方向

宿主使用 loader 和所需组件。组件仅依赖必要的 core 约定以及明确的外部能力。core 不反向依赖组件；组件之间不隐式初始化彼此。

统一组件约定包括 ID、组件版本、接口版本、运行时要求、资源根目录和 dispose。键盘的 open、词库、候选等能力属于 keyboard，不进入所有组件的公共接口。

## 分发

源码分发：发布源码包，由使用方 Falcon 工具链编译进 AMR。各包版本独立，根仓库和初始占位包保持 private；npm 名称尚未注册或验证可用。

公共目录分发：构建经验证的运行时产物，安装到设备公共目录；应用带小型宿主适配和 loader。源包版本、接口版本、词库版本、QuickJS/平台产物要求分别记录。

组件使用宿主 Vue/Falcon 渲染环境。资源路径从组件根目录解析，组件不覆盖宿主 setViewPort、不调用业务服务、不假设浏览器 DOM 或 Node API 存在。

## 生命周期

组件安装文件可以共享；模块实例和会话数据通常仍在各应用进程内。模块缓存可复用，输入状态须隔离。close 清理会话，dispose 清理组件资源；不承诺模块或字节码可以卸载。

## 当前证据

初始化设计参考了本机 aiot-vue-cli 1.0.32 的 Vue/npm 解析和包内页面 import 路径；这些信息不是公开稳定 API 保证。包外加载、外部样式注册及多固件兼容尚未验证，需记录目标固件和实测结果。
