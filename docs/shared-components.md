# 设备公共目录方案

目录示例：

```text
/userdisk/components/falcon-components/
  hello/
    0.1.0/
      manifest.json
      hello.mjs
      assets/
      dictionaries/
  <其他组件>/
    <version>/
```

根路径由宿主配置，示例不是库内硬编码路径。manifest v1 记录组件 ID、版本、接口与运行时配置、入口和含大小/SHA-256 的文件列表。格式见 [GitHub 更新源](github-source.md)，存储和加载接口见 [宿主适配](host-adapters.md)。本版尚不支持组件间运行时依赖。

## 加载顺序

1. 宿主选择组件和兼容版本。
2. 本地缺失时由前台询问用户；确认后 loader 获取清单并检查运行时兼容性。
3. 加锁、复查本地、下载与逐文件校验、原子发布完整目录；再由宿主加载入口。
4. 当前应用挂载 UI，创建独立会话。
5. 关闭时清理会话资源，模块缓存可保留。

文件权限按 root 可读处理。仍需验证包外路径是否可被 Falcon 运行时接受、依赖如何解析、编译后样式如何注册、资源是否可从外部目录读取，以及 QuickJS 字节码版本/配置是否匹配。

不直接复制另一个应用的构建产物并假设可用，也不直接替换 QuickJS 全局模块加载器破坏宿主内置模块。若原加载器不支持公共目录，先提出范围明确的宿主适配方案。

## 更新

各组件使用不可变版本目录；应用指定精确版本，checkUpdate 只报告目录中的新版本。完整安装后再让宿主选择新版本。进行中的会话继续使用其原版本，不覆盖已加载文件或承诺热替换模块。保留旧版本供兼容应用使用；本版没有自动卸载和旧版本清理功能。

## 最小验证

电脑参考实现已可验证下载/安装、普通 ESM 加载、两个管理器共用目录及实例隔离。设备端先使用 Hello 验证无第三方依赖的包外模块，再检查含样式和资源的 Vue 组件；分别记录普通 JS 和生产字节码路径，随后使用两个独立 AppID 验证。

记录型号、固件、Falcon/QuickJS 配置、工具链、安装与启动方式、产物哈希、结果和关键日志。框架实现、Node 运行、Falcon 编译和设备动态加载是独立证据；设备验证成功前不能宣称所有词典笔已经支持。
